# Development transcripts

This site was built with [Claude Code](https://claude.com/claude-code). This folder holds transcripts of those development sessions, so you can follow how the exposition, the demos and the code took shape: the questions asked, the decisions made, and the revisions requested along the way.

| Transcript | What happened |
| --- | --- |
| [2026-11-16-initial-build.md](2026-11-16-initial-build.md) | Reviewing the project brief, building the math engine and the five interactive demos, several rounds of feedback on the text and interactions, and the first GitHub Pages deployment. |

## Notes

- Transcripts are exported with Claude Code's `/export` command and named `YYYY-MM-DD-short-description.md`.
- Before committing, local details are replaced with placeholders: `<repo>` for the local checkout path, `<scratchpad>/` for the session's temporary directory, `<username>` for the local account name, and `<custom-domain>` for a personal domain.
- Some tool output appears in collapsed form (for example "ran 2 shell commands"), as `/export` writes it.
- These files are for reference only. They are not part of the website build.
